# فیدیبو کیدز · نسخهٔ ارائه

این بسته برای ارائه طراحی شده است. نقطهٔ شروع `/` صفحهٔ نمایشی فیدیبو است؛ با انتخاب «کیدز» وارد جریان فیدیبو کیدز می‌شوید.

- ورود والد از `/parent` یا «ورود والدین» انجام می‌شود. برای ارائهٔ سریع، هر شمارهٔ معتبر با کد نمایشی `۱۲۳۴` وارد خانوادهٔ نمونه می‌شود.
- داشبورد والد از طرح Figma الهام گرفته و انتخاب کودک، گزارش فعالیت و تنظیمات را دارد. انتخاب کودک از داشبورد با یک کلیک وارد فضای همان کودک می‌شود و رمز دوباره پرسیده نمی‌شود.
- ورود مستقیم کودک در این نسخه با کد `۱۲۳۴` است.
- `/expert` همچنان با رمز فعلی پنل کارشناس فیدیبو کیدز کار می‌کند.

برای اتصال حمایت مالی، مقدار `KIDSBOOK_DONATION_URL` را با یک لینک HTTPS واقعی در محیط اجرای سرور تنظیم کنید. تا آن زمان دکمهٔ پرداخت عمداً غیرفعال می‌ماند.

اجرا: `start_admin.bat` در ویندوز یا `python -m uvicorn app.main:app --host 0.0.0.0 --port 8000` پس از نصب `requirements.txt`. برای HTTPS، `KIDSBOOK_SECURE_COOKIES=1` را فعال کنید.
