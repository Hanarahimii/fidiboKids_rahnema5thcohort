# فیدیبو کیدز · نسخهٔ تست کاربردپذیری

این بسته برای لینک عمومی تست ساخته شده است. مسیر `/` مستقیماً یک نشست ناشناس کودک می‌سازد و بدون رمز وارد خانهٔ کیدز می‌شود. هر مرورگر شناسهٔ آزمایشی جدا دارد.

- والد و ورود نمایشی والد در این نسخه غیرفعال است.
- پنل کارشناس در `/expert` مستقل است و رمز فعلی آن حفظ شده است.
- از صفحهٔ «بازخورد و حمایت» می‌توان امتیاز و نظر ثبت کرد؛ اطلاعات شخصی کودک یا شماره تماس لازم نیست.
- پاک‌کردن نشست، پروفایل آزمایشی و بازخورد همان مرورگر را حذف می‌کند.
- برای پرداخت واقعی، مقدار `KIDSBOOK_DONATION_URL` را با لینک HTTPS درگاه تنظیم کنید؛ بدون لینک واقعی هیچ مبلغی دریافت نمی‌شود.

اجرا: `start_admin.bat` در ویندوز یا `python -m uvicorn app.main:app --host 0.0.0.0 --port 8000` پس از نصب `requirements.txt`. در استقرار عمومی HTTPS و `KIDSBOOK_SECURE_COOKIES=1` الزامی است.
