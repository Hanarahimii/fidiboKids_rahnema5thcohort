فیدیبو کیدز — نسخهٔ ارائهٔ v4 (حمایت با دو پیوند، ۱۴۰۵/۰۷/۰۴)

۱) روی فایل ZIP راست‌کلیک کنید و Extract All / استخراج همه را بزنید.
۲) وارد پوشهٔ استخراج‌شده شوید و روی OPEN_FIDIBO_KIDS.bat دوبارکلیک کنید.
۳) پنجرهٔ مشکی را باز نگه دارید. وقتی برنامه آماده شود، صفحهٔ ارائه در مرورگر باز می‌شود.

این نسخه از صفحهٔ فیدیبو شروع می‌شود. برای ورود به تجربهٔ کودک، «کیدز» را انتخاب کنید.

برای تنظیم لینک‌های حمایت، به مسیر /expert بروید، وارد پنل کارشناس شوید و تب «پیوندهای حمایت» را باز کنید. لینک درگاه، لینک پرداخت مستقیم و شماره کارت ۱۶ رقمی را ثبت و ذخیره کنید. تا پیش از ثبت اطلاعات، گزینه‌ها در صفحهٔ حمایت غیرفعال‌اند. لینک‌ها باید با https:// شروع شوند. پیوندها و شماره کارت در پایگاه دادهٔ همان پوشه ذخیره می‌شوند.

پیش‌نیاز: Windows و Python 3.12. اگر Python نصب نیست، آن را از
https://www.python.org/downloads/
نصب کنید و گزینهٔ Add python.exe to PATH را هنگام نصب فعال کنید. اجرای اول برای نصب کتابخانه‌های Python به اینترنت نیاز دارد؛ دفعات بعد از همان محیط استفاده می‌شود.

برای توقف برنامه پنجرهٔ مشکی را ببندید یا Ctrl+C بزنید.
اگر مرورگر خودکار باز نشد، آدرسی را که کنار Opening در پنجره چاپ شده است باز کنید.

این بسته از نسخهٔ v4 دوستتان ساخته شده است. نماد ماهیِ تب حذف شده؛ صفحهٔ فیدیبو نشان فیدیبو و صفحات کیدز نشان نارنجی فیدیبو دارند. محیط Python وابسته به کامپیوتر او حذف شده و راه‌انداز مناسب کامپیوتر شما به بسته اضافه شده است.
