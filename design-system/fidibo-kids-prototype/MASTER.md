# سیستم طراحی فیدیبو کیدز — نسخهٔ پروتوتایپ

این سند بر اساس تصویر پالت `fidibo Colors.jpg` و قلم `Kahroba-FD` از پوشهٔ دارایی‌های فیدیبو نوشته شده است. لوگوی فیدیبو در آن پوشه استفاده نمی‌شود؛ فقط `LOGO-V2.png` ارسالی کارفرما در رابط قرار گرفته است. پیشنهاد عمومی اسباب‌بازی‌وار ابزار طراحی به درخواست کارفرما برای مخاطب حدود ۱۰ سال تغییر داده شد.

## جهت بصری

کتابی، امروزی، آرام و مناسب نوجوان کم‌سن: زمینهٔ کاغذی روشن، متن تیره با فاصلهٔ خواندنی، بنر تصویری واضح و رنگ برند به مقدار کنترل‌شده. حباب، ایموجی‌های تزئینی، سایهٔ سنگین و CTAهای متعدد حذف شوند.

## رنگ‌های اجرایی

| نقش | مقدار | استفاده |
|---|---|---|
| زمینه | `#f9f6f2` | صفحهٔ کتاب و پنل |
| سطح | `#fffdfa` | کارت/خواندن |
| متن اصلی | `#242321` | متن روی زمینهٔ روشن |
| متن کمکی | `#655e60` | توضیح‌ها |
| بنفش اصلی | `#633f99` | دکمه و انتخاب |
| بنفش برند | `#9c57ff` | حلقهٔ فوکوس و جزئیات |
| مرجانی | `#f54d4c` | نشانه‌های کوتاه و توجه، نه متن ریز روی سفید |
| آبی تیره | `#0f4e93` | رنگ فرعی در صورت نیاز |
| خط | `#e5dfe7` | مرز کارت‌ها |

رنگ‌های برند از ردیف‌های تصویری فایل `fidibo Colors.jpg` انتخاب شده‌اند. نقش‌های خنثی برای خوانایی به آن‌ها افزوده شده‌اند. تعریف اجرایی در `frontend/src/fidibo.css` است.

## تایپوگرافی و رقم

خانوادهٔ کهربا با نسخهٔ ارقام فارسی: `Kahroba-FD-RG.woff2` برای متن و `Kahroba-FD-B.woff2` برای تأکید. این فونت به‌دلیل شرط منع بازنشر داخل بستهٔ کد کپی نشده است؛ کاربر با `install_brand_font.bat` و نسخهٔ مجاز خود آن را در `runtime/brand_fonts` نصب می‌کند. fallback: Tahoma. رشته‌های عددی پویا با `persianDigits()` در UI نمایش داده می‌شوند؛ شناسه‌های API تغییر نمی‌کنند.

## الگوها

- جلد: تیتر کوتاه، توضیح مختصر، یک CTA اصلی و تصویر قابل ویرایش از پنل.
- نقشهٔ داستان: شبکهٔ منظم کارت گام، یک عنوان و یک وضعیت پیشرفت.
- صفحهٔ خواندن: متن در زمینهٔ روشن، تصویر با اندازهٔ مشخص، سوییچ روشن میان خواندن و شنیدن.
- پنل: نوار بالایی + ساختار صفحات + پیش‌نمایش؛ ابزار بنر جدا ولی در همان پنل.
- پژوهش: خوانایی وضعیت‌ها و تمایز صدای خام از صدای منتشرشده.

## معیار پذیرش بصری

کنترل‌ها حداقل ۴۴ پیکسل، متن اصلی حداقل ۱۶ پیکسل، حلقهٔ فوکوس برای کیبورد، نسبت کنتراست قابل قبول، ارتفاع ثابت تصویر برای جلوگیری از جهش چیدمان، حالت کاهش حرکت، خوانایی در عرض‌های ۳۷۵/۷۶۸/۱۰۲۴/۱۴۴۰ پیکسل، و تداوم مسیر ضبط با رضایت و انتشار انسانی.
